# cults-game-design-project
## Cults - Caça ao Tesouro

Projeto interdisciplinar desenvolvido durante minha graduação em Sistemas de Informação. O projeto consistiu na concepção e prototipação de um jogo educacional/trivia para dispositivos móveis, utilizando Unity.

O jogo utilizava mecânicas de progressão, desafios, pontuação/XP, recompensas e interação com QR Codes durante uma experiência de visita a museu.

Minha participação esteve concentrada principalmente na elaboração e estruturação da documentação do projeto (Game Design Document), com uma contribuição menor na etapa de desenvolvimento.

Este foi meu primeiro contato acadêmico com um projeto de desenvolvimento de jogos e contribuiu para meu interesse pela área de game development.
